HTML Containers

Containers

Any element with an opening tag and a closing tag.

<div>

Generic block conatiner with no meaning of its own. This tag is useless w/o a class or id attribute

<span>

Generic inline container with no meaning of its own. This tag is useless w/o a class or id attribute

Block vs Inline

Block Conatiner (Element) - Starts on a new line and stretches across its parent conatiners full width.
Inline Container (element) - Stays in the flow of the line and takes only as much room as its content.

Other Block Level elements

Examples:

  • Paragraph Element <p>
  • Unordered List Element <ul>
  • Header Element <h1>,<h2>, etc

Inline Level elements

  • Strong Element <strong>
  • Underline Element <u>
  • Bold Element <b>

Semantic Element

<article> Element - This contains content that can stand alone outside of the context of the current web page.

<aside> Element - This contains content that indirectly relates to the current web page, and is not part of the main content. An example of an aside would be an advertising link on a website, which is often created in a section off to the right-side of a page. Weather
